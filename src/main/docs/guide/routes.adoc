=== Java DSL

Every bean of type `RoutesBuilder`, such as a `RouteBuilder`, `EndpointRouteBuilder` or `RouteConfigurationBuilder`, is added to Camel when the application starts. Route builders are created after the `CamelContext` bean, so they can inject it, the Camel templates, and any other bean:

snippet::io.micronaut.camel.docs.routes.PriceService[tags="service", indent=0, title="A service"]

snippet::io.micronaut.camel.docs.routes.PriceRoutes[tags="routes", indent=0, title="A route calling the service"]

<1> The route builder receives the service through its constructor.
<2> The route invokes the `priceOf` method of the service.

Routes can also be declared as lambdas, with `LambdaRouteBuilder`, or with `LambdaEndpointRouteBuilder` for the type-safe https://camel.apache.org/manual/Endpoint-dsl.html[Endpoint DSL], which needs the `camel-endpointdsl` dependency:

snippet::io.micronaut.camel.docs.routes.ShippingRoutes[tags="routes", indent=0, title="Lambda routes"]

<1> A route written with the Java DSL.
<2> A route written with the Endpoint DSL.

The `camel.main.java-routes-include-pattern` and `camel.main.java-routes-exclude-pattern` options select which route builder classes are added.

=== YAML DSL

With the `camel-yaml-dsl` dependency, Camel loads the YAML routes found by `camel.main.routes-include-pattern`, which by default is `classpath:camel/*,classpath:camel-template/*,classpath:camel-rest/*`:

dependency:org.apache.camel:camel-yaml-dsl[]

[source,yaml]
.src/main/resources/camel/notifications.yaml
----
include::test-suite/src/test/resources/camel/notifications.yaml[tags=routes]
----

YAML routes call Micronaut beans by name, as described in <<beans, Beans and the Camel Registry>>.
