Micronaut Camel

Integration between Micronaut and Apache Camel

Version: 1.0.0-SNAPSHOT

1 Introduction

This project integrates Apache Camel with Micronaut. Camel routes are written in the Java DSL or the YAML DSL, and they run inside the Micronaut application context: Micronaut beans are visible to Camel’s registry, and Micronaut configuration resolves Camel’s property placeholders.

The integration targets Camel 4 and Micronaut 5. Camel components are added as plain Camel dependencies, such as org.apache.camel:camel-kafka, and configured under camel.component.<name>. No Micronaut-specific artifact is needed per component.

This project is under development.

2 Quick Start

Add the Micronaut Camel dependency to your build:

implementation("io.micronaut.camel:micronaut-camel-core")
<dependency>
    <groupId>io.micronaut.camel</groupId>
    <artifactId>micronaut-camel-core</artifactId>
</dependency>
[tool.pyronaut.dependencies]
runtime = [
    "io.micronaut.camel:micronaut-camel-core",
]
